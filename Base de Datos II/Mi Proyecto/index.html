Circuito de Ventas y Pedidos de Clientes

Gestiona la facturación, los pedidos efectuados por los clientes y la deducción automática de stock en SQLite.

Tabla Campo Tipo de Dato (SQLite) Clave Descripción
ventas id INTEGER PK Identificador único autoincremental
cliente_id INTEGER FK Referencia a la tabla clientes
fecha_emision DATETIME - Fecha y hora del pedido
total REAL - Monto total calculado
detalle_ventas id INTEGER PK ID del ítem en detalle
producto_id INTEGER FK Referencia al producto vendido
cantidad INTEGER - Unidades vendidas

Adquisición de Materia Prima y Gestión de Compras

Permite registrar las órdenes de compra a proveedores y el ingreso de insumos para la producción.

Tabla Campo Tipo de Dato (SQLite) Clave Descripción
materias_primas id INTEGER PK ID único del insumo
nombre_insumo TEXT - Nombre de la materia prima
unidad_medida TEXT - Kg, Litros, Unidades, Metros
ordenes_compra id INTEGER PK Número de orden de compra
proveedor_id INTEGER FK Proveedor adjudicado
estado TEXT - Pendiente, Recibido, Cancelado

Control de Stock y Alertas de Reorden

Monitoreo en tiempo real de las existencias disponibles y cálculo de alertas de stock mínimo.

Tabla Campo Tipo de Dato (SQLite) Clave Descripción
inventario id INTEGER PK ID del registro de stock
item_id INTEGER FK ID de producto o materia prima
stock_actual REAL - Cantidad física disponible
stock_minimo REAL - Umbral para disparar reorden

4. Guía de GitHub, Variables de Entorno & Laravel Asistido

Configuración integral de Git en tu PC, flujo de trabajo con comandos de sincronización e instalación asistida de Laravel con el Agente.

Factor Clave 4: Configuración Global de Git y Setup Asistido

Configurarás tus variables globales de Git para autorizar y registrar cada cambio (add, commit, push, fetch, pull) y utilizarás la asistencia del agente IA (Antigravity) para inicializar Laravel con SQLite en tu repositorio local.

1. Dar de alta en GitHub & Crear el Repositorio

  1. Ingresa a github.com y crea una cuenta gratuita (o inicia sesión si ya posees una).
  2. Haz clic en New repository y nómbralo mi-proyecto-bd2.
  3. Puedes marcarlo como Público o Privado y marcar la casilla "Add a README file".
  4. Haz clic en Create repository y copia la URL HTTPS de clonado (ejemplo: https://github.com/tu-usuario/mi-proyecto-bd2.git).

2. Configurar Variables de Entorno Globales de Git en tu PC

Antes de interactuar con el repositorio, debes configurar tu identidad en la terminal (PowerShell o Git Bash). Estos datos identificarán la autoría de tus commits:

Terminal / PowerShell (Configuración de Identidad) 
# 1. Configurar tu nombre de autor
git config --global user.name "Tu Nombre y Apellido"

# 2. Configurar tu correo vinculado a GitHub
git config --global user.email "tu-email@ejemplo.com"

# 3. Establecer 'main' como rama por defecto
git config --global init.defaultBranch main

# 4. Verificar que los datos se guardaron correctamente
git config --list

💡 Nota: Solo necesitas ejecutar esta configuración una sola vez en tu computadora.

3. Clonar, Modificación de Prueba & Flujo Completo de Envíos (Push)

Sigue esta secuencia paso a paso para clonar en XAMPP, hacer un cambio de prueba y enviarlo a GitHub:

Paso A: Clonar en XAMPP

PowerShell / CMD 
cd c:/xampp/htdocs
git clone https://github.com/tu-usuario/mi-proyecto-bd2.git
cd mi-proyecto-bd2

Paso B: Modificación Simple de Prueba

PowerShell / CMD 
# Agregar una línea de prueba al README.md
echo "Prueba de conexion Git - Base de Datos 2" >> README.md

Paso C: Secuencia de Comandos para Confirmar y Enviar (Push)

PowerShell / CMD (Ciclo Git Completo) 
# 1. Ver qué archivos cambiaron
git status

# 2. Agregar todos los cambios al área de preparación
git add .

# 3. Guardar el commit con un mensaje descriptivo
git commit -m "Primer commit de prueba: configuracion de entorno"

# 4. Enviar los cambios a la rama principal en GitHub
git push origin main

🔄 Comandos de Sincronización para más adelante:

  • git fetch: Consulta los cambios existentes en GitHub sin alterar tus archivos locales.
  • git pull origin main: Descarga y combina automáticamente las actualizaciones remotas en tu proyecto.

4. Composer & Instalación de Laravel Asistida por el Agente

Para evitar complicaciones manuales con dependencias y entorno, la instalación y configuración de Laravel se realizará con la asistencia directa del Agente IA (Antigravity).

Paso 4.1: Descarga y Verificación de Composer

  1. Abre tu terminal y verifica si Composer ya está instalado:
    Terminal 
    composer --version
  2. Si no está instalado, ingresa a getcomposer.org, descarga el instalador Composer-Setup.exe para Windows y ejecútalo.
  3. Durante la instalación, asegúrate de que seleccione la ruta de PHP de XAMPP (habitualmente C:\xampp\php\php.exe).

Paso 4.2: Solicitar la Instalación de Laravel a Antigravity

Una vez clonado el repositorio y con Composer listo, pídele a tu Agente IA que cree el proyecto Laravel y configure SQLite ejecutando el siguiente prompt:

Prompt para el Agente Antigravity 
Hola Antigravity! Estoy ubicado en la carpeta de mi repositorio clonado en c:/xampp/htdocs/mi-proyecto-bd2.
Por favor:
1. Instala Laravel en esta carpeta (composer create-project laravel/laravel .).
2. Configura el archivo .env para usar SQLite (DB_CONNECTION=sqlite) y crea database/database.sqlite si no existe.
3. Ejecuta las migraciones iniciales (php artisan migrate).
4. Asegúrate de configurar la estructura para usar Pure CSS en public/css/ y JavaScript Vanilla sin dependencias pesadas.

⚡ El agente se encargará de ejecutar los comandos en segundo plano, validar la estructura y dejar el entorno listo para desarrollar los circuitos.

6. Diseño de Interfaz Sólida, Backend & Componentes UI

Preguntas clave para el diseño frontend/backend, flujo ordenado de un módulo CRUD con filtros, prompts para conectar la base de datos y guía de componentes.

Factor Clave 6: Interfaz Sólida Conectada al Backend

Una aplicación sólida responde a preguntas de experiencia de usuario antes de codificar, utiliza componentes modulares consistentes y conecta los endpoints de Laravel mediante peticiones asíncronas limpias con SQLite.

1. Preguntas Clave para Diseñar una Interfaz Sólida y Funcional con Backend

Antes de redactar prompts o maquetar pantallas, responde a estas preguntas para asegurar una experiencia robusta y conectada:

1. Visualización & Jerarquía

¿Qué datos son indispensables ver a primera vista? (Tablas limpias, tarjetas con totales y badges de estado).

2. Captura & Validación

¿Cómo ingresa la información el usuario? (Modales con inputs controlados y validación en frontend y Laravel).

3. Búsqueda & Filtrado

¿Cómo filtrará el operador? (Buscador instantáneo por texto, selects por categoría/estado y ordenamiento).

4. Feedback & Carga

¿Qué respuesta recibe el usuario al interactuar? (Spinners durante peticiones, alertas toast y confirmaciones).

5. Proceso Estratégico

¿Qué lógica de negocio se dispara? (Descuento automático de inventario, recálculo de costos y alerta de stock mínimo).

6. Integridad de Datos

¿Las operaciones multi-tabla son atómicas? (Uso de DB::transaction en Laravel para evitar inconsistencias).

2. Instrucciones Ordenadas de Ejemplo: Módulo CRUD + Filtrados

Secuencia recomendada para construir un módulo completo (ej: Gestión de Ventas o Materia Prima):

  1. Paso 1: Rutas y Controlador en Laravel — Definir el recurso en routes/web.php y crear el controlador con los métodos index(), store(), update(), destroy() y filter().
  2. Paso 2: Maquetación Base (HTML Semántico & Pure CSS) — Crear la vista con la barra superior de acciones (Buscador, Selects de filtro, Botón "Nuevo Registro") y la tabla de datos con cabeceras claras.
  3. Paso 3: Ventana Modal de Alta / Edición — Implementar un modal emergente con el formulario de carga para que el usuario registre datos sin cambiar de página.
  4. Paso 4: Conexión Asíncrona con Fetch API (Vanilla JS) — Enviar los datos del formulario en formato JSON o FormData a Laravel, cerrar el modal, actualizar la tabla en vivo y disparar un toast de éxito.
  5. Paso 5: Filtrado y Búsqueda en Tiempo Real — Escuchar eventos input en el buscador y change en los selects para filtrar dinámicamente las filas de la tabla.

3. Guía de Prompting: Cómo Pedirle a la IA Vincular la Base de Datos

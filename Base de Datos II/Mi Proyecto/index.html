Articulación Interdisciplinaria

Unión sinérgica entre la estrategia comercial (Emprendimientos) y la ingeniería de software (Base de Datos II).

Materia: Emprendimientos

Definición del modelo de negocio, identidad de marca y seguimiento comercial.

  • Branding & Eslogan: Creación del nombre, propuesta de valor y logotipo del proyecto.
  • Estrategia Comercial: Definición de clientes ideales, canales de venta y precios.
  • Gestión de Operaciones: Identificación del circuito de materia prima y productos.

Materia: Base de Datos II

Diseño e implementación del sistema web funcional que soporta las operaciones.

  • Modelo Relacional en SQLite: Tablas, campos y claves sin requerir servidor MySQL.
  • Desarrollo Web en Laravel: Implementación con PHP, HTML, JavaScript y Vanilla CSS.
  • Flujo Agéntico (Antigravity): Automatización de un proceso estratégico clave de negocio.

Modelado de Datos (SQLite) & Procesos de Negocio

Diseño estructural de tablas relacionales sobre motor SQLite, evitando la necesidad de ejecutar MySQL en XAMPP.

Formato de Base de Datos: SQLite Embebido

Para este proyecto no utilizaremos el servidor MySQL de XAMPP. La base de datos será un archivo liviano SQLite almacenado en database/database.sqlite dentro de tu proyecto Laravel.

Configuración en archivo .env de Laravel 
DB_CONNECTION=sqlite
# No se requieren campos DB_HOST, DB_PORT, DB_USERNAME ni DB_PASSWORD

Circuito de Ventas y Pedidos de Clientes

Gestiona la facturación, los pedidos efectuados por los clientes y la deducción automática de stock en SQLite.

Tabla Campo Tipo de Dato (SQLite) Clave Descripción
ventas id INTEGER PK Identificador único autoincremental
cliente_id INTEGER FK Referencia a la tabla clientes
fecha_emision DATETIME - Fecha y hora del pedido
total REAL - Monto total calculado
detalle_ventas id INTEGER PK ID del ítem en detalle
producto_id INTEGER FK Referencia al producto vendido
cantidad INTEGER - Unidades vendidas

Adquisición de Materia Prima y Gestión de Compras

Permite registrar las órdenes de compra a proveedores y el ingreso de insumos para la producción.

Tabla Campo Tipo de Dato (SQLite) Clave Descripción
materias_primas id INTEGER PK ID único del insumo
nombre_insumo TEXT - Nombre de la materia prima
unidad_medida TEXT - Kg, Litros, Unidades, Metros
ordenes_compra id INTEGER PK Número de orden de compra
proveedor_id INTEGER FK Proveedor adjudicado
estado TEXT - Pendiente, Recibido, Cancelado

Control de Stock y Alertas de Reorden

Monitoreo en tiempo real de las existencias disponibles y cálculo de alertas de stock mínimo.

Tabla Campo Tipo de Dato (SQLite) Clave Descripción
inventario id INTEGER PK ID del registro de stock
item_id INTEGER FK ID de producto o materia prima
stock_actual REAL - Cantidad física disponible
stock_minimo REAL - Umbral para disparar reorden

Requerimiento de Proceso Estratégico

El desarrollo en Laravel no debe limitarse a un simple CRUD (Altas, Bajas y Modificaciones). Debes implementar un proceso estratégico como:

  • Deducción automática de materias primas e insumos al confirmar un pedido de producción.
  • Cálculo dinámico del margen de ganancia en base al costo actualizado de insumos.
  • Generación automática de sugerencia de compras cuando el stock cae debajo del mínimo.

Guía de Configuración & Entorno de Desarrollo

Pautas paso a paso para GitHub, Composer y la creación de tu proyecto Laravel con SQLite.

Mini Guía: Dar de alta en GitHub

  1. Ingresa a github.com y crea una cuenta gratuita.
  2. Crea un repositorio llamado mi-proyecto-bd2 (marca la opción Público o Privado).
  3. Abre la consola de comandos en tu computadora y navega a la carpeta de XAMPP:
Terminal / PowerShell 
cd c:/xampp/htdocs
git clone https://github.com/tu-usuario/mi-proyecto-bd2.git

Mini Guía: Composer, Laravel & SQLite

  1. Verifica si tienes Composer instalado ejecutando composer --version. Si no lo tienes, descárgalo de getcomposer.org.
  2. Crea el proyecto Laravel en c:/xampp/htdocs y ejecuta las migraciones SQLite:
Terminal / PowerShell 
cd c:/xampp/htdocs
composer create-project laravel/laravel mi-proyecto-bd2
cd mi-proyecto-bd2
php artisan migrate

JS Arrays y Listas (Colecciones de Datos)

Aprende a almacenar, manipular y ordenar listas de elementos utilizando arreglos en JavaScript.

📦 Concepto Fundamental: ¿Qué es un Array?

Un Array (o arreglo / lista) es una estructura de datos que permite almacenar múltiples valores en una sola variable ordenada. Cada elemento dentro del array se ubica en una posición numerada llamada índice, comenzando siempre desde el índice 0.

A diferencia de las variables simples que guardan un único dato, las listas nos permiten organizar colecciones de números, textos, objetos e incluso otros arreglos.

📝 1. Declaración y Asignación de Valores

Sintaxis Literal `[]` Corchetes

Se declara una lista encerrando los elementos entre corchetes [] separados por comas. Puede ser vacía o inicializada.

let vacio = []; // Array vacío
let numeros = [10, 20, 30, 40];
let mixto = [100, "UNER", true, null];

Acceso y Modificación `array[i]` Índice Directo

Los arrays son mutables. Se puede leer o sobrescribir un elemento asignándole un nuevo valor mediante su índice.

let marcas = ["Ford", "Fiat", "Toyota"];
// Leer el primer elemento
console.log(marcas[0]); // "Ford"
// Reemplazar el segundo elemento
marcas[1] = "Chevrolet";

🛠️ 2. Operaciones Básicas con Listas (`push`, `pop`, `shift`, `unshift`, `splice`)

push() y pop() Extremo Final

push(valor) agrega uno o varios elementos al final de la lista. pop() elimina y retorna el último elemento.

let pila = ["A", "B"];
pila.push("C"); // ["A", "B", "C"]
let eliminado = pila.pop(); // Retorna "C"
unshift() y shift() Extremo Inicial

unshift(valor) inserta al principio (reorganizando los índices). shift() remueve el primer elemento (índice 0).

let fila = [2, 3];
fila.unshift(1); // [1, 2, 3]
fila.shift(); // Remueve el 1
💡 Curiosidad de JavaScript: Las Cadenas de Texto (Strings) trabajan como Listas de Caracteres

En JS, una cadena de texto se comporta internamente de forma muy similar a un array de caracteres. Puedes acceder a cada letra usando la notación entre corchetes string[i] y consultar su longitud con .length.

⚠️ Diferencia de Mutabilidad: Un Array es mutable (puedes hacer array[0] = "X"), mientras que un String es inmutable (si intentas hacer string[0] = "X", JS ignora el cambio).

JS Manejo del DOM (Selección, Texto y Estilos)

Aprende a conectar JavaScript con el HTML de tu página: busca elementos, modifica sus textos y cambia sus estilos dinámicamente.

⚙️ Ciclo de Vida y Orden de Ejecución: ¿Cuál entra en acción al final?

Cuando el navegador abre una página web, no carga todo de golpe. Sigue un pipeline secuencial estricto para procesar la información:

1. HTML Parsing

Lee la estructura HTML y construye el árbol de nodos en memoria conocido como DOM (Document Object Model).

2. CSS Render Tree

Descarga las reglas CSS, calcula la especificidad y pinta el layout visual (Render Tree) en la pantalla.

3. JavaScript (Último) 🔥

¡JavaScript es el ÚLTIMO en actuar! Se ejecuta al final para alterar el DOM y los estilos dinámicamente según las acciones del usuario.

⚠️ Problema Común (Script en Header): Si ejecutas document.getElementById("miBoton") en un <script> ubicado en la etiqueta <head> sin diferir, JS intentará buscar el elemento antes de que el HTML haya sido leído, resultando en un error de puntero nulo (Cannot read properties of null).
💡 Solución: Ubica el script antes del cierre de </body>, usa el atributo defer o escucha el evento DOMContentLoaded.

🔍 1. Selección de Elementos en el DOM

Para modificar un elemento con JavaScript, primero debes encontrarlo en el árbol del DOM.

Método de Selección Sintaxis de Búsqueda Tipo de Retorno Actualización
getElementById("id") ID exacto (sin #) Element único (o null) Estática / Única
querySelector("selector") Selector CSS (#id, .clase, tag) Primer Element coincidente Estática / Única
querySelectorAll("selector") Selector CSS completo NodeList (soporta .forEach) Colección Estática
getElementsByClassName("clase") Nombre de clase (sin .) HTMLCollection Colección En Vivo (Live)

📝 2. Modificación de Contenido (`innerText` vs `textContent` vs `innerHTML`)

innerText vs textContent Texto Plano

innerText lee únicamente el texto visible respetando los estilos CSS (ignora elementos ocultos). textContent obtiene todo el contenido de texto crudo (más rápido).

let elem = document.getElementById("titulo");
elem.innerText = "Nuevo Título Visible";
elem.textContent = "Texto Crudo Incluyendo Ocultos";
innerHTML (y Riesgo XSS) Interpretador HTML

innerHTML parsea e interpreta etiquetas HTML (como <strong> o <a>).

⚠️ Alerta XSS: Nunca asignes valores directo de un usuario a innerHTML sin sanitizar, ya que atacantes podrían inyectar código malicioso (Cross-Site Scripting).

elem.innerHTML = "<strong>¡Texto en Negrita!</strong>";

🎨 3. Manipulación de Estilos y Clases CSS

Estilos Directos (`element.style`) CamelCase

Se modifican propiedades CSS convirtiendo guiones a camelCase (ej: background-color ➔ backgroundColor).

💡 Nota de Especificidad: Los estilos mediante .style aplican como atributo de estilo en línea, teniendo la máxima especificidad (valor 1000).

elem.style.backgroundColor = "#38bdf8";
elem.style.fontSize = "20px";
elem.style.display = "none"; // Ocultar
Administración de Clases (`classList`) Recomendado

En lugar de escribir estilos en línea, es mejor práctica alternar clases CSS predefinidas en tus hojas de estilo usando classList.

elem.classList.add("activo");
elem.classList.remove("oculto");
elem.classList.toggle("modo-oscuro"); // Alterna
let tiene = elem.classList.contains("activo");

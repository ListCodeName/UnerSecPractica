JS Funciones y Modularización

Una función es un bloque de código reutilizable diseñado para realizar una tarea específica, recibir parámetros de entrada y retornar un resultado.

💡 Curiosidad: "Casi todo lo que has usado son Funciones Nativas"

¿Sabías que la mayoría de los métodos que hemos utilizado hasta ahora son en realidad funciones predefinidas por el entorno de JavaScript?

Un Método es simplemente una función que se encuentra guardada dentro de la propiedad de un objeto (ej: log() dentro del objeto console).

console.log("Hola")

Función de impresión en consola del objeto console.

document.getElementById("id")

Función de búsqueda del objeto global document.

JSON.stringify(objeto)

Función de serialización del objeto nativo JSON.

🧩 Anatomía y Componentes de una Función

Toda función se compone de cuatro elementos fundamentales para su funcionamiento:

1. Nombre / Firma

Identificador de la función en camelCase (ej: calcularTotal).

2. Parámetros

Variables de entrada entre paréntesis (precio, iva).

3. Cuerpo {}

Bloque de instrucciones a ejecutar al ser invocada.

4. Sentencia return

Devuelve el valor final e interrumpe la función.

📝 1. Formas de Declarar Funciones

Declaración vs Expresión Sintaxis

Las Declaraciones tradicionales se elevan (Hoisting). Las Expresiones asignan la función a una constante y solo se pueden invocar después de su línea de definición.

// Declaración (con Hoisting):
function multiplicar(a, b) { return a * b; }

// Expresión (sin Hoisting):
const multiplicar = function(a, b) { return a * b; };
Funciones Flecha (`=>`) ES6 Moderno

Sintaxis moderna compacta. Si el cuerpo tiene 1 sola expresión, omitimos llaves y la palabra return.

// Retorno Implícito de una línea:
const doble = n => n * 2;

// Múltiples líneas requieren llaves y return:
const area = (b, h) => {
  return (b * h) / 2;
};

⚠️ 2. Errores Comunes y Problemas en el Llamado

1. Olvidar Paréntesis o `return`

🔴 Sin paréntesis (saludar): Referencias la función sin ejecutarla (imprime su código fuente).
🔴 Sin return: La función ejecuta pero retorna undefined por defecto.

console.log(saludar); // f saludar(n) { ... } (No ejecutó)
console.log(saludar()); // "Hola Juan!" (Sí ejecutó)
2. ReferenceError & TypeError

🔴 ReferenceError: Intentar leer fuera de la función una variable local.
🔴 TypeError: fn is not a function: Intentar invocar un número o nulo como si fuera función.

let num = 5;
num(); // ❌ Uncaught TypeError: num is not a function

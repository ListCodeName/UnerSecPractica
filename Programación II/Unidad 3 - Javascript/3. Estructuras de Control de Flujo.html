JS Estructuras de Control de Flujo

Aprende a tomar decisiones (Condicionales) y a repetir tareas automáticamente (Bucles) en JavaScript.

🚦 Concepto Fundamental: ¿Qué es una Condición?

Por defecto, una computadora lee el código en orden secuencial (de arriba a abajo, línea por línea). Una condición es una pregunta lógica cuya respuesta es únicamente un valor booleano: true (verdadero) o false (falso).

Las Estructuras de Control de Flujo nos permiten romper esa secuencia plana y decirle al programa: "Si la condición es verdadera haz el camino A; si no, haz el camino B" o "Repite este bloque de código MIENTRAS la condición siga siendo verdadera".

🔀 1. Estructuras Condicionales (`if`, `if-else`, `switch`)

if / else / else if Bifurcación Lógica

Evalúa condiciones de mayor a menor jerarquía. Si una condición es verdadera, ejecuta su bloque e ignora el resto.

if (edad >= 18) {
  mensaje = "Acceso permitido";
} else if (edad > 0) {
  mensaje = "Acceso denegado";
} else {
  mensaje = "Edad no válida";
}

switch Casos Exactos

Ideal para comparar el mismo valor exacto contra múltiples alternativas conocidas (días, roles, menús).

switch (dia) {
  case 1: nom = "Lunes"; break;
  case 2: nom = "Martes"; break;
  default: nom = "Día no válido";
}

🔄 2. Estructuras Repetitivas o Bucles (`while`, `for`)

bucle while Indeterminado / Condicional

Repite la ejecución mientras la condición sea true. Se usa cuando no sabemos cuántas veces exactamente se repetirá el proceso.

let num = 1;
while (num < 100) {
  console.log(num);
  num = num * 2; // ¡Crucial cambiar num!
}

Resultado: Listo para ejecutar...
bucle for Determinado / Contado

Se usa cuando conocemos de antemano el número de iteraciones. Consta de inicialización, condición e incremento.

for (let i = 1; i <= 5; i++) {
  console.log(`Vuelta N° ${i}`);
}

💥 Curiosidad y Advertencia: Bucles Infinitos y la cláusula break

1. El Bucle Infinito: Si olvidas modificar la variable de control en un while (por ejemplo, si nunca haces i++), la condición siempre será true. ¡El navegador se congelará consumiendo el 100% de la CPU!

2. Fallthrough en Switch: Si no pones la instrucción break al final de un case en un switch, el código "caerá" y ejecutará todos los casos siguientes, aunque sus condiciones sean falsas.

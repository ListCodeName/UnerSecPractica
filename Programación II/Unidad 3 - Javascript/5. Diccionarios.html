Aprende a agrupar datos relacionados con estructuras clave: valor en JavaScript.

🔑 Concepto Fundamental: ¿Qué es un Objeto / Diccionario?

Un Objeto (también llamado Diccionario o Mapa) es una entidad que almacena colecciones de propiedades compuestas por pares clave: valor (en inglés, key: value). Se declaran mediante llaves {}.

A diferencia de los Arrays que ordenan sus datos por índices numéricos (0, 1, 2...), los Objetos nos permiten acceder a la información mediante nombres descriptivos (por ejemplo: persona.nombre o producto.precio).

📝 1. Declaración, Notaciones y Métodos

Punto `.` vs Corchetes `[]` Sintaxis

Usa notación de punto (obj.nombre) habitualmente. Usa corchetes (obj[variable]) si el nombre de la clave se encuentra en una variable o tiene espacios/caracteres especiales.

let auto = { marca: "Toyota", "tipo auto": "SUV" };
let propiedad = "marca";
console.log(auto.marca); // "Toyota"
console.log(auto[propiedad]); // Dinámico -> "Toyota"
console.log(auto["tipo auto"]); // Con espacio

Métodos y Puntero `this` Funciones

Una función guardada dentro de la propiedad de un objeto se llama método. Dentro del método, this hace referencia al objeto contenedor.

let usuario = {
  nombre: "Ana",
  saludar: function() {
    return \`Hola, soy \${this.nombre}\`;
  }
};

🏢 2. Estructuras Complejas (Arrays de Objetos y Objetos Anidados)

Objetos Anidados Jerarquía

Un objeto puede contener otros objetos como valor de sus propiedades, permitiendo crear estructuras jerárquicas encadenadas.

let empresa = {
  nombre: "Tech Corp",
  contacto: {
    email: "info@tech.com",
    telefono: "422-1000"
  }
};
// Acceso encadenado: empresa.contacto.email
Arreglos de Objetos Colección

Es el formato estándar en desarrollo web (APIs / Bases de datos) para representar registros o listas de entidades.

let productos = [
  { id: 1, nombre: "Mouse", precio: 1500 },
  { id: 2, nombre: "Teclado", precio: 3500 }
];
// Acceso: productos[0].nombre -> "Mouse"
💡 Curiosidad: Serialización JSON y Congelamiento de Objetos (`Object.freeze`)

JSON (JavaScript Object Notation) es el formato de texto más usado para enviar datos entre un servidor y un navegador. Se convierte un objeto a texto con JSON.stringify() y de texto a objeto con JSON.parse().

❄️ Object.freeze(obj): Congela un objeto impidiendo que se le agreguen, eliminen o modifiquen propiedades.

🧮 Bloque 1: Operaciones Aritméticas

Se utilizan para realizar cálculos matemáticos entre números o variables numéricas.

+ - * /

Básicas

Suma, resta, multiplicación y división estándar.

let res = (10 + 5) * 2; // 30
% (Módulo)

Residuo de la División

Devuelve el resto que sobra de una división entera. ¡Ideal para saber si un número es par!

let resto = 10 % 3; // 1
** (Exponente)

Potenciación

Eleva la base al exponente indicado (ES6).

let cubo = 2 ** 3; // 8
++ --

Incremento y Decremento

Aumenta o disminuye el valor de la variable en 1 unidad.

let n = 5; n++; // n pasa a ser 6

🔤 Bloque 2: Operaciones con Strings (Cadenas)

Permiten manipular, unir y formatear textos dentro del código.

+ (Concatenación)

Unión Clásica

Une dos o más cadenas de texto en una sola.

let msj = "Hola " + "Mundo";
${} (Template String)

Interpolación Moderna

Permite incrustar variables directamente dentro de acentos graves `` ` ` ``.

let saludo = `Hola ${nombre}`;
.length / .toUpperCase()

Métodos Útiles

Propiedades y funciones integradas para transformar el texto.

"hola".length; // 4
"hola".toUpperCase(); // "HOLA"

🤯 Curiosidad de Coerción: "5" + 2 vs "5" - 2

¿Sabías que en JavaScript "5" + 2 da "52", pero "5" - 2 da 3?

Explicación: El operador + está sobrecargado: si uno de los dos lados es un String, convierte todo a String y los **concatena**. Sin embargo, el operador - solo existe para números, por lo que JavaScript convierte automáticamente el "5" a número y realiza la **resta matemática**.

🧠 Bloque 3: Operaciones Lógicas

Combinan expresiones booleanas para tomar decisiones complejas en el código.

&& (AND / Y)

Ambos Verdaderos

Retorna true únicamente si **ambas** condiciones son verdaderas.

true && false; // false
|| (OR / O)

Al Menos Uno Verdadero

Retorna true si **al menos una** de las condiciones es verdadera.

true || false; // true
! (NOT / Negación)

Inversión Lógica

Invierte el valor booleano: true pasa a ser false y viceversa.

!true; // false

💡 Concepto Clave: Valores Truthy y Falsy en JS

En JS, cualquier valor se puede evaluar como booleano en una condición. Los 6 valores Falsy principales son:

false 0 "" (String vacío) null undefined NaN

¡Cualquier otro valor (números no cero, textos no vacíos, arrays o objetos) es considerado Truthy!

🔍 Bloque 4: Operaciones Relacionales (Comparación)

Comparan dos valores y siempre devuelven un valor booleano (true o false).

=== vs ==

Igualdad Estricta vs Laxa

=== compara Valor Y Tipo (recomendado).
== intenta convertir tipos antes de comparar (no recomendado).

5 == "5"; // true ⚠️
5 === "5"; // false ✅
!== vs !=

Desigualdad Estricta vs Laxa

Verifica si dos elementos son diferentes.

10 !== "10"; // true
> < >= <=

Comparación de Orden

Mayor que, menor que, mayor o igual, menor o igual.

18 >= 18; // true

⚠️ La Paradoja de NaN (Not a Number)

NaN representa un resultado matemático inválido (ejemplo: "hola" * 2).

¡La curiosidad es que NaN === NaN devuelve false! Es el único valor en todo JavaScript que no es igual a sí mismo. Para saber si una variable es NaN, se debe usar la función Number.isNaN(valor).

JS Eventos y Manejo de Interacciones

Los eventos son señales que se emiten en la página (clics, teclas, movimientos de mouse o envío de formularios) y que JavaScript escucha para responder dinámicamente.

⚡ Comandos Mínimos Esenciales para el Manejo de Eventos

Para escuchar y responder a cualquier evento en JavaScript sólo necesitas dominar esta pequeña cheatsheet de comandos:

elemento.addEventListener("click", callback);

Registra un "escuchador" de eventos. Ejecuta la función callback cada vez que el evento ocurre.

elemento.removeEventListener("click", funcionRef);

Remueve un listener previamente registrado (requiere la misma referencia a la función).

e.preventDefault();

Cancela la acción nativa por defecto (ej: recargar la página en <form> o navegar en <a>).

e.stopPropagation();

Detiene la propagación del evento hacia arriba en el árbol DOM (Burbujeo de eventos).

📝 1. Formas de Escuchar Eventos

1. Atributos HTML y Propiedad JS Limitado

Usar atributos HTML (onclick="...") o asignar propiedades (elem.onclick = funcion) es una mala práctica pues solo permite 1 función escuchando al mismo tiempo (sobrescribe la anterior).

// ❌ Mala práctica en HTML:
<button onclick="saludar()">Clic</button>

// ⚠️ Limitado en JS (sobrescribe el anterior):
elem.onclick = function() { ... };
2. addEventListener() Estándar

Es el método profesional recomendado. Permite adjuntar múltiples funciones escuchando el mismo evento sin sobrescribirse y separar la lógica JS del marcado HTML.

let btn = document.getElementById("miBtn");
btn.addEventListener("click", function(e) {
  console.log("¡Múltiples escuchadores activos!");
});

📦 2. El Objeto Event (`e` / `event`) y Métodos Clave

`e.target` vs `e.currentTarget` Propiedades

Cuando se dispara una función listener, recibe automáticamente un parámetro (usualmente nombrado e o event) con información contextual.

  • e.target: El elemento exacto que fue cliqueado o accionado.
  • e.currentTarget: El elemento que tiene registrado el listener.
`e.preventDefault()` Control

Evita el comportamiento por defecto de ciertos elementos HTML (como recargar la página en un <form> o navegar a una URL en un enlace <a>).

form.addEventListener("submit", function(e) {
  e.preventDefault(); // Detiene el envío por defecto
  console.log("Formulario procesado con JS sin recargar");
});
💡 Curiosidades: Delegación de Eventos y Funciones Anónimas
🚀 1. Delegación de Eventos (Event Delegation):

En lugar de agregar 100 listeners a 100 etiquetas <li> en una lista, adjunta UN solo listener al padre <ul> y usa e.target para averiguar a qué hijo se le hizo clic. ¡Ahorra memoria y procesador!

⚠️ 2. ¿Por qué falla `removeEventListener` con funciones anónimas?:

removeEventListener requiere exactamente la misma referencia de memoria que addEventListener. Si usaste function() {} anónima, JavaScript crea dos funciones distintas en memoria y nunca podrá removerla. Debes usar funciones con nombre referenciado.

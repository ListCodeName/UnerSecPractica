JS Variables y Tipos de Datos

Guía interactiva para dominar los cimientos de JavaScript: declaración de variables, almacenamiento en memoria y clasificación de datos primitivos.

⚡ 1. Formas de Declarar Variables

Una variable es un contenedor en memoria donde guardamos un valor para reutilizarlo o modificarlo más adelante.

var Antiguo (ES5)

Tiene alcance de función (o global). Permite re-declaración y sufre de hoisting. No se recomienda usar actualmente.

var nombre = "Carlos";
var nombre = "Ana"; // ¡Sin error!
let Moderno (ES6+)

Tiene alcance de bloque { }. Se puede **reasignar** (cambiar su valor), pero **no re-declarar** en el mismo bloque.

let contador = 1;
contador = 2; // Reasignación OK
const Recomendado

De alcance de bloque. Es **constante**: debe inicializarse al declararse y **no se puede reasignar** su referencia.

const PI = 3.1416;
// PI = 3.14; ❌ Error!
💡 Curiosidad JS: ¿Qué es el Alcance de Bloque (Block Scope)?

A diferencia de var, las variables declaradas con let o const dentro de llaves { ... } (como en un if o for) existen solamente dentro de esas llaves. ¡Esto evita que sobrescribas variables accidentales de otras partes del código!

🧩 2. Tipos de Datos Primitivos

Los tipos primitivos representan un único valor inmutable directamente en memoria.

String (Texto) "hola"

Secuencias de caracteres encerrados entre comillas simples ' ', dobles " " o *template literals* `` ` ` ``.

let saludo = `Hola ${nombre}`;
Number (Número) 42 / 3.14

JavaScript no distingue entre enteros y decimales. Todos son Number (formato IEEE 754 a 64 bits).

let precio = 19.99;
Boolean (Lógico) true / false

Solo puede tomar dos valores: verdadero (true) o falso (false). Ideal para tomar decisiones.

let activo = true;
Undefined (Sin definir) undefined

Es el valor por defecto que asigna JavaScript automáticamente a una variable declarada sin inicializar.

let x; // x vale undefined
Null (Nulo intencional) null

Representa la **ausencia intencional** de cualquier valor o referencia a un objeto.

let usuario = null;
BigInt (Enteros grandes) 9007199254740991n

Para números enteros de precisión arbitraria mayores al límite seguro de Number. Se forma con una n al final.

const numGrande = 9007199254740995n;
🐞 Curiosidad Histórica: El bug de "typeof null"

Si ejecutas typeof null en la consola, JavaScript devolverá "object".

¡Esto es un bug histórico reconocido desde la primera versión de JS en 1995! Nunca se corrigió porque arreglarlo rompería millones de páginas web antiguas que dependen de ese comportamiento.

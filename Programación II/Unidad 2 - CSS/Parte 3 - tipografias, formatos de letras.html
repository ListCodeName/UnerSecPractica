📐 Font-size

Unidades de medida, escalas tipográficas y decisiones de tamaño

▶

font-size controla el tamaño de las letras. En CSS existen varias unidades, y elegir la correcta tiene impacto directo en la accesibilidad, la responsividad y el mantenimiento del proyecto.

CSS – Unidades para font-size
.elemento {
  /* ── px: píxeles absolutos ── */
  font-size: 16px;  /* fijo, no respeta preferencias del usuario */

  /* ── rem: relativo al root (<html>) ── */
  font-size: 1rem;    /* = 16px si el navegador usa 16px base */
  font-size: 1.5rem;  /* = 24px  ✓ respeta preferencias del usuario */

  /* ── em: relativo al padre ── */
  font-size: 1.2em;   /* 120% del font-size del elemento padre */
  /* ⚠ puede acumularse si hay anidamiento */

  /* ── % : igual que em ── */
  font-size: 120%;

  /* ── vw / vh: relativo al viewport ── */
  font-size: 4vw;     /* 4% del ancho de la pantalla */

  /* ── clamp(): mínimo | ideal | máximo ✓ MODERNO ── */
  font-size: clamp(1rem, 2.5vw, 2rem);
  /*               ↑min   ↑fluido   ↑max  */
}
💡 ¿Por qué preferir rem sobre px?
Cuando un usuario configura el navegador con una fuente más grande (por accesibilidad), px ignora esa configuración. rem la respeta. Además, si necesitás escalar toda la tipografía, solo cambiás el font-size del <html>.

📏 Escala tipográfica — tamaños con propósito

En diseño, los tamaños no son arbitrarios. Hay convenciones que facilitan la jerarquía visual:

10–11px Micro — etiquetas, badges, legal (⚠ cuidado con legibilidad)
12–13px Auxiliar — metadatos, timestamps, captions
14–15px UI pequeña — botones, inputs, navegación
16px (base) Body — el estándar de legibilidad web (1rem)
18–20px Subtítulos, párrafos destacados, leads
24–32px H3 / H2 — encabezados de sección
40–56px H1 — Héroe

🔤 Font-family & Font-weight

Fuentes predefinidas, importadas y el peso tipográfico desde el ojo del diseñador

▶

🔤 Font-family

font-family define la tipografía. Se declara como una lista de respaldo (font stack): si la primera fuente no está disponible, el navegador prueba la siguiente. Siempre se termina con una generic family (serif, sans-serif, monospace…).

CSS – font-family
body {
  /* Stack de sans-serif del sistema (sin carga de red) */
  font-family: -apple-system, BlinkMacSystemFont, "Segoe UI",
               Roboto, Oxygen, Ubuntu, sans-serif;

  /* Fuente importada de Google Fonts */
  font-family: "Inter", sans-serif;
}

/* ── @import en CSS (al inicio del archivo) ── */
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap');

/* ── <link> en HTML (más rápido, en el <head>) ── */
<link href="https://fonts.googleapis.com/css2?family=Inter..." rel="stylesheet">

/* ── @font-face: fuente local propia ── */
@font-face {
  font-family: "MiFuente";
  src: url('fuente.woff2') format('woff2'),
       url('fuente.woff')  format('woff');
  font-display: swap; /* evita texto invisible durante la carga */
}
⚠️ Fuentes Web-Safe vs Google Fonts
Las web-safe fonts (Arial, Georgia, Times New Roman…) están instaladas en casi todos los sistemas operativos y no requieren carga de red. Las Google Fonts ofrecen mucha más variedad pero suman una petición HTTP — usá el atributo display=swap para evitar que la página se quede sin texto mientras cargan.

⚖️ Font-weight — Peso tipográfico

font-weight controla el grosor de la tipografía. Va del 100 (Thin) al 900 (Black). Desde la perspectiva del diseño gráfico, el peso es una herramienta de jerarquía: los pesos más gruesos atraen la vista primero.

CSS – font-weight
.elemento {
  font-weight: 400;   /* Regular — lectura de cuerpo */
  font-weight: normal; /* equivalente a 400 */
  font-weight: 700;   /* Bold — énfasis, títulos */
  font-weight: bold;   /* equivalente a 700 */

  /* Escala completa */
  font-weight: 100; /* Thin — decorativo, delicado */
  font-weight: 200; /* ExtraLight */
  font-weight: 300; /* Light — subtítulos, captions */
  font-weight: 400; /* Regular ← cuerpo de texto 
  font-weight: 500; /* Medium — botones, navegación */
  font-weight: 600; /* SemiBold — etiquetas, UI */
  font-weight: 700; /* Bold ← encabezados principales */
  font-weight: 800; /* ExtraBold — héroes, impacto */
  font-weight: 900; /* Black — display, máximo impacto */
}
🎨 Perspectiva del diseñador gráfico
En tipografía, el peso es contraste. Un título en 800 sobre cuerpo en 400 crea una diferencia de 400 puntos — suficiente para que el ojo lo distinga de inmediato. Usar pesos intermedios (500, 600) en la UI añade jerarquía sin agresividad: ideal para botones y etiquetas que deben destacar pero no gritar. Evitá usar 900 en bloques de texto: fatiga la lectura. Reservalo para 2-4 palabras de impacto máximo por pantalla.

✍️ Text-decoration, Text-indent & más

Decoraciones de texto, sangría y otras propiedades de formato

▶

CSS ofrece un conjunto de propiedades que controlan cómo se presenta el texto más allá de su fuente: subrayados, tachados, sangrías, espaciados y transformaciones.

〰 Text-decoration

CSS – text-decoration completo
a {
  /* Shorthand: línea | estilo | color | grosor */
  text-decoration: underline solid #7c5cfc 2px;

  /* ── Propiedades individuales ── */
  text-decoration-line:      underline;   /* underline | overline | line-through | none */
  text-decoration-style:     solid;       /* solid | double | dotted | dashed | wavy */
  text-decoration-color:     #7c5cfc;     /* cualquier color */
  text-decoration-thickness: 2px;         /* grosor de la línea */

  /* Quitar subrayado de un link */
  text-decoration: none;

  /* Offset: separar el subrayado del texto */
  text-underline-offset: 4px;
}
🔗 Usos habituales de text-decoration
  • underline → links, términos glosados, énfasis semántico
  • line-through → precios tachados, ítems completados en listas
  • overline → raro en web; algunos diseños editoriales
  • wavy + color rojo → errores ortográficos (como en editores de texto)
  • none → quitar el subrayado nativo de los <a> para diseñar links personalizados

⤵ Text-indent

CSS – text-indent y otras propiedades de párrafo
p {
  /* Sangría de primera línea */
  text-indent: 2em;     /* sangría tipográfica tradicional */
  text-indent: 32px;

  /* Sangría negativa (hanging indent) */
  text-indent: -1.5em;
  padding-left: 1.5em;  /* compensar la sangría negativa */

  /* Alineación del texto */
  text-align: left;      /* izquierda (default) */
  text-align: center;    /* centrado */
  text-align: right;     /* derecha */
  text-align: justify;   /* justificado (⚠ cuidado con rivers) */

  /* Otras propiedades útiles */
  line-height:     1.6;    /* interlineado (sin unidad = escalable) */
  letter-spacing:  0.05em; /* tracking — espacio entre letras */
  word-spacing:    0.1em;  /* espacio entre palabras */
  text-transform:  uppercase; /* uppercase | lowercase | capitalize */
  white-space:     nowrap;    /* evitar salto de línea */
}

🎨 Color & Efectos Especiales de Texto

Texto con gradiente, stroke, clip-path, opacidad y más

▶

Más allá del color sólido, CSS permite aplicar efectos visuales sofisticados directamente sobre el texto: gradientes, contornos, transparencia y efectos de recorte — sin imágenes ni SVG.

CSS – Efectos especiales de color en texto
/* ── 1. Color sólido (base) ── */
.titulo { color: #7c5cfc; }

/* ── 2. Texto con gradiente (truco background-clip) ── */
.grad-text {
  background: linear-gradient(135deg, #7c5cfc, #e040fb, #00e5ff);
  -webkit-background-clip: text;   /* recorta el fondo a la forma del texto */
  -webkit-text-fill-color: transparent; /* hace transparente el fill del texto */
  background-clip: text;           /* estándar (sin prefijo) */
}

/* ── 3. Texto solo contorno (stroke) ── */
.stroke-text {
  color: transparent;
  -webkit-text-stroke: 2px #7c5cfc; /* grosor | color */
}

/* ── 4. Contorno + relleno de distinto color ── */
.stroke-fill {
  color: #0d0f1a;                   /* relleno */
  -webkit-text-stroke: 2px #e040fb; /* borde */
}

/* ── 5. Opacidad del texto ── */
.muted {
  color: rgba(255,255,255,0.5); /* semitransparente */
  /* alternativa: opacity afecta a TODO el elemento */
  opacity: 0.5;
}

/* ── 6. Gradiente animado (bonus) ── */
.animated-grad {
  background: linear-gradient(90deg, #7c5cfc, #e040fb, #00e5ff, #7c5cfc);
  background-size: 200%;
  -webkit-background-clip: text;
  -webkit-text-fill-color: transparent;
  background-clip: text;
  animation: moveGrad 3s linear infinite;
}
@keyframes moveGrad {
  0%   { background-position: 0%; }
  100% { background-position: 200%; }
}

💫 Sombras de texto (text-shadow)

Anatomía, efectos modernos, cuándo usarlas y cuándo no

▶

text-shadow agrega una o más sombras detrás del texto. Acepta múltiples sombras separadas por coma, lo que permite construir efectos complejos combinando capas.

CSS – Anatomía de text-shadow
.elemento {
  /* offset-x | offset-y | blur-radius | color */
  text-shadow: 2px  4px  8px  rgba(0,0,0,.5);
  /*             ↑x    ↑y   ↑blur ↑color          */
  /* x+ = derecha  x- = izquierda                 */
  /* y+ = abajo    y- = arriba                     */
  /* blur=0 → sombra nítida                        */

  /* ── Sin offset → solo brillo (glow) ── */
  text-shadow: 0 0 20px #00e5ff;

  /* ── Múltiples sombras (separadas por coma) ── */
  text-shadow:
    0 0   6px  #00e5ff,   /* capa 1: glow suave */
    0 0   20px #00e5ff,   /* capa 2: glow medio */
    0 0   40px #00e5ff;   /* capa 3: glow amplio */

  /* ── Long shadow (sombra larga, diseño flat) ── */
  text-shadow:
    1px 1px 0 #5a2e8a, 2px 2px 0 #5a2e8a,
    3px 3px 0 #5a2e8a, 4px 4px 0 #5a2e8a,
    5px 5px 0 #5a2e8a, 6px 6px 0 #5a2e8a;
}

🧠 ¿Cuándo usar sombras de texto?

✅ Usá text-shadow cuando…
texto sobre imagen efecto neon / glow jerarquía en hero estética retro/gaming legibilidad en fondos variables
Una sombra suave (0 2px 4px rgba(0,0,0,.5)) sobre texto blanco en una foto mejora la legibilidad sin cambiar el diseño.
🚫 No uses text-shadow cuando…
texto de cuerpo largo tamaños pequeños (<14px) fondos blancos sin propósito múltiples sombras sin criterio UI minimalista / corporativa
Las sombras añaden ruido visual en textos pequeños y reducen la legibilidad. En UI corporativa suelen parecer desactualizadas. Menos es más.

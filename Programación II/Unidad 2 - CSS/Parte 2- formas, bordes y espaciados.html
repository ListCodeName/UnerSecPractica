🎨 Color

Formatos de color en CSS: named, HEX, RGB, HSL y transparencia

▶

CSS acepta el color en múltiples formatos. Todos son equivalentes: elegí el que mejor se adapte al contexto. Los más usados son HEX (diseño) y HSL (control intuitivo de tono/saturación/luminosidad).

CSS – Todos los formatos de color
.elemento {
  /* 1. Nombre de color (148 nombres disponibles) */
  color: tomato;
  color: cornflowerblue;

  /* 2. HEX – #RRGGBB o abreviado #RGB */
  color: #e040fb;      /* 6 dígitos */
  color: #f0b;         /* abreviado = #ff00bb */
  color: #e040fb88;    /* + 2 dígitos de alpha */

  /* 3. RGB / RGBA – canales rojo, verde, azul (0-255) */
  color: rgb(224, 64, 251);
  color: rgba(224, 64, 251, 0.5); /* alpha: 0=transparente 1=sólido */

  /* 4. HSL – tono (0-360°) saturación% luminosidad% */
  color: hsl(291, 96%, 62%);
  color: hsla(291, 96%, 62%, 0.4);

  /* 5. Sintaxis moderna (CSS Color Level 4) */
  color: rgb(224 64 251 / 50%); /* sin comas */
}
💡 ¿Cuándo usar HSL?
HSL brilla cuando necesitás crear variaciones de un mismo color: solo cambiás la luminosidad para obtener versiones más claras u oscuras. Ej: hsl(291,96%,62%) → oscuro: hsl(291,96%,30%) → claro: hsl(291,96%,85%).

🔲 Bordes & Border-Radius

Grosor, estilo, color y redondeo de esquinas

▶

La propiedad border controla el contorno visible de un elemento. Se compone de tres partes que se pueden declarar juntas o por separado: grosor · estilo · color.

CSS – Anatomía del border
/* ── Shorthand: grosor | estilo | color ── */
.caja {
  border: 3px solid #7c5cfc;
}

/* ── Propiedades individuales ── */
.caja {
  border-width: 3px;          /* grosor */
  border-style: solid;        /* estilo (ver abajo) */
  border-color: #7c5cfc;      /* color */
}

/* ── Por lado: top | right | bottom | left ── */
.caja {
  border-top:    4px solid  #e040fb;
  border-right:  2px dashed #00e5ff;
  border-bottom: 4px solid  #00e676;
  border-left:   0;               /* sin borde */
}

/* ── outline: similar al border pero NO ocupa espacio ── */
.caja:focus {
  outline: 2px solid #7c5cfc;
  outline-offset: 4px;   /* separación del elemento */
}

🎨 Estilos de borde disponibles

⭕ Border-radius

border-radius redondea las esquinas. Acepta de 1 a 4 valores (como el padding/margin) y también admite valores distintos para radio horizontal y vertical con /.

CSS – Border-radius
.caja {
  /* Un valor → todas las esquinas iguales */
  border-radius: 8px;

  /* Dos valores → TL+BR  |  TR+BL */
  border-radius: 8px 24px;

  /* Cuatro valores → TL | TR | BR | BL (agujas del reloj) */
  border-radius: 8px 24px 8px 0;

  /* Círculo perfecto */
  border-radius: 50%;

  /* Forma "píldora" */
  border-radius: 999px;

  /* Radio elíptico: horizontal / vertical */
  border-radius: 40% 60% / 60% 40%;
}

📦 Padding & Margin

El modelo de caja: espaciado interior vs. exterior

▶

Todo elemento HTML es una caja compuesta de capas. Padding es el espacio interior (entre el contenido y el borde). Margin es el espacio exterior (entre el borde y otros elementos).

margin
border
padding
contenido
⚠️ Diferencia clave
El padding tiene el mismo fondo que el elemento y es clickeable. El margin es siempre transparente y colapsa verticalmente entre elementos (margin collapsing).
CSS – Padding & Margin: sintaxis completa
/* ── Shorthand: un valor → los 4 lados ── */
padding: 16px;

/* ── Dos valores: vertical | horizontal ── */
padding: 12px 24px;

/* ── Tres valores: top | horizontal | bottom ── */
padding: 8px 16px 24px;

/* ── Cuatro valores: top | right | bottom | left ── */
padding: 8px 16px 24px 32px;

/* ── Propiedades individuales ── */
padding-top:    8px;
padding-right:  16px;
padding-bottom: 8px;
padding-left:   16px;

/* ── Exactamente igual para margin ── */
margin: 0 auto;   /* centrar horizontalmente */
margin-top: 24px;

/* ── box-sizing: incluye padding+border en el width ── */
* { box-sizing: border-box; } /* ¡recomendado siempre! */
📐 box-sizing: border-box
Por defecto (content-box) si un elemento tiene width:200px y padding:20px, su ancho total es 240px. Con border-box el ancho total sigue siendo 200px (el padding se resta del espacio interior). Esto es mucho más predecible y por eso casi todos los proyectos aplican * { box-sizing: border-box } globalmente.

🌈 Background: Colores & Gradientes

Fondos sólidos, lineales, radiales y cónicos

▶

La propiedad background (o background-color) define el fondo de un elemento. Puede ser un color sólido, una imagen, o un gradiente — un degradado suave entre dos o más colores generado directamente en CSS, sin necesitar una imagen.

CSS – Background color
.caja {
  background-color: #7c5cfc;    /* color sólido */
  background-color: transparent; /* sin fondo     */

  /* shorthand "background" acepta múltiples capas */
  background: #7c5cfc;
}

🌈 Gradientes

CSS – Tipos de gradiente
/* ── 1. Linear gradient ── */
background: linear-gradient(135deg, #7c5cfc, #e040fb);
/*                          ↑ dirección   ↑ color inicio  ↑ color fin */

/* Dirección con palabras clave */
background: linear-gradient(to right, #7c5cfc, #00e5ff);
background: linear-gradient(to bottom right, #7c5cfc, #e040fb);

/* Múltiples colores (color stops) */
background: linear-gradient(90deg,
  #7c5cfc 0%,
  #e040fb 50%,
  #00e5ff 100%
);

/* ── 2. Radial gradient ── */
background: radial-gradient(circle, #e040fb, #0d0f1a);
background: radial-gradient(ellipse at top left, #7c5cfc, #0d0f1a);

/* ── 3. Conic gradient ── */
background: conic-gradient(from 0deg, #e040fb, #7c5cfc, #00e5ff, #e040fb);

/* ── 4. Capas múltiples (se apilan de arriba a abajo) ── */
background:
  linear-gradient(rgba(0,0,0,.4), rgba(0,0,0,.4)),  /* capa oscura */
  url('foto.jpg') center/cover;              /* imagen base */

🖼 Background con Imágenes

Posición, tamaño, repetición y trucos de adaptación

▶

Para poner una imagen de fondo usamos background-image. Las propiedades complementarias controlan cómo se posiciona, repite y escala esa imagen.

CSS – Background image y sus compañeras
.hero {
  background-image:    url('imagen.jpg');

  /* ── background-size ── */
  background-size: cover;    /* cubre TODO el contenedor (puede recortar) */
  background-size: contain;  /* se ve COMPLETA (puede dejar espacio vacío) */
  background-size: 300px 200px; /* tamaño fijo */
  background-size: 100% auto;  /* 100% ancho, alto proporcional */

  /* ── background-position ── */
  background-position: center;        /* centrada */
  background-position: top left;      /* esquina superior izquierda */
  background-position: 50% 20%;       /* x% y% */

  /* ── background-repeat ── */
  background-repeat: no-repeat; /* sin repetición (más común) */
  background-repeat: repeat;    /* repite en X e Y (patrón) */
  background-repeat: repeat-x;  /* solo en horizontal */

  /* ── background-attachment ── */
  background-attachment: fixed;  /* efecto parallax */
  background-attachment: scroll; /* se mueve con la página (default) */
}

/* ── Shorthand completo ── */
.hero {
  background: url('imagen.jpg') center/cover no-repeat fixed;
  /*           ↑url            ↑pos   ↑size  ↑repeat  ↑attach */
}

🪄 Trucos de adaptación de imágenes

CSS – object-fit para <img> en contenedor
/* object-fit: para imágenes <img> con ancho/alto fijo */
img.avatar {
  width: 120px;
  height: 120px;
  object-fit: cover;    /* recorta, no deforma ✓ */
  object-fit: contain;  /* se ve completa */
  object-fit: fill;     /* deforma (evitar) */
  object-position: top center; /* elige qué parte mostrar */

  /* Esquinas redondeadas en imagen */
  border-radius: 50%; /* círculo */
}

/* Imagen responsive que no desborda */
img {
  max-width: 100%;  /* nunca más ancha que su contenedor */
  height: auto;     /* mantiene proporción */
  display: block;   /* elimina espacio inferior de inline */
}

/* Aspecto ratio fijo independiente del tamaño */
.card-image {
  aspect-ratio: 16/9; /* mantiene 16:9 siempre */
  object-fit: cover;
  width: 100%;
}

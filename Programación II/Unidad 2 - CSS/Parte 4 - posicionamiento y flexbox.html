📍 CSS Position — Los 5 tipos

static, relative, absolute, fixed, sticky + trucos de centrado

▶

position controla cómo se coloca un elemento dentro del documento. Cambia si el elemento respeta el flujo normal del HTML o si flota por encima, anclado a otro elemento o a la ventana del navegador. Es la base de los modales, menús flotantes, headers pegajosos y tooltips.

static
Default. Flujo normal. Ignora top/left/right/bottom.
relative
Se desplaza desde su posición original. Sigue en el flujo.
absolute
Sale del flujo. Se posiciona respecto al ancestro posicionado más cercano.
fixed
Sale del flujo. Se ancla al viewport (la ventana). Permanece al scrollear.
sticky
Híbrido: flujo normal hasta un umbral de scroll, luego se "pega".
static — Es el valor por defecto de todo elemento HTML. El elemento se coloca exactamente donde le corresponde en el flujo normal del documento. Las propiedades top, right, bottom, left y z-index son ignoradas completamente.
¿Ocupa espacio en el flujo? ✓ En el flujo
CSS – Los 5 tipos de position
/* ── static: valor por defecto, no necesita declararse ── */
.caja { position: static; }

/* ── relative: se desplaza DESDE su posición natural ── */
.caja {
  position: relative;
  top: 20px;   /* 20px hacia ABAJO */
  left: 30px;  /* 30px hacia la DERECHA */
  /* El espacio original se CONSERVA (las otras cajas no se mueven) */
}

/* ── absolute: se posiciona respecto al PADRE posicionado ── */
.padre { position: relative; }  /* ← NECESARIO como referencia */
.hijo {
  position: absolute;
  top: 0;  right: 0;  /* esquina superior derecha del padre */
  /* SALE del flujo — las otras cajas lo ignoran */
}

/* ── fixed: se ancla al VIEWPORT (ventana del navegador) ── */
.menu-flotante {
  position: fixed;
  bottom: 24px;  right: 24px;
  /* Permanece visible aunque el usuario haga scroll */
}

/* ── sticky: flujo normal + se "pega" al hacer scroll ── */
.header {
  position: sticky;
  top: 0;  /* umbral: cuando top=0 respecto al viewport, se pega */
  /* NECESITA que el contenedor padre tenga altura suficiente */
}

🎯 Propiedades de desplazamiento

CSS – top, right, bottom, left, z-index
.caja {
  position: absolute;

  /* Los 4 lados — solo aplican si position ≠ static */
  top:    20px;  /* distancia desde el borde superior del referente */
  right:  10px;  /* distancia desde el borde derecho  */
  bottom: 0;     /* distancia desde el borde inferior */
  left:   50%;   /* acepta %, px, rem, vw… */

  /* inset: shorthand de top+right+bottom+left (moderno) */
  inset: 0;           /* todos = 0 */
  inset: 10px 20px;   /* vertical | horizontal */

  /* z-index: orden de apilamiento (más alto = encima) */
  z-index: 10;   /* solo funciona si position ≠ static */
  z-index: -1;   /* detrás del contenido normal */
}

✦ Trucos de centrado con position

CSS – Centrado con position: absolute
/* ── Técnica 1: clásica con transform ── */
.padre { position: relative; }
.centrado {
  position: absolute;
  top:  50%;
  left: 50%;
  transform: translate(-50%, -50%);
  /* top/left mueven la esquina superior-izq al centro,  */
  /* transform:translate mueve el elemento -50% de SÍ MISMO */
}

/* ── Técnica 2: moderna con inset + margin auto ── */
.centrado {
  position: absolute;
  inset: 0;         /* ocupa toda la referencia */
  margin: auto;     /* el navegador centra automáticamente */
  width: 200px;    /* DEBE tener dimensiones definidas */
  height: 100px;
}

/* ── Técnica 3: solo centrado vertical (para badges/tooltips) ── */
.badge {
  position: absolute;
  top: 50%;
  transform: translateY(-50%);
  right: 12px;
}

📦 Flexbox — Distribución inteligente

display:flex, ejes, justify-content, align-items, gap, flex-direction

▶

Flexbox (Flexible Box Layout) es un modelo de layout unidimensional: organiza elementos en una fila o columna. A diferencia de position, Flexbox distribuye espacio automáticamente entre los hijos de un contenedor, sin necesidad de conocer sus tamaños exactos.

💡 Dos niveles de propiedades
Flexbox tiene propiedades para el contenedor (display:flex, justify-content, align-items, gap, flex-direction…) y propiedades para los hijos (flex-grow, flex-shrink, align-self, order…).

(align-items)
Con flex-direction: row (default): el eje principal va de izquierda a derecha, el cruzado de arriba a abajo.
Con flex-direction: column: el eje principal baja verticalmente, el cruzado va horizontal.
CSS – Flexbox completo
/* ═══ CONTENEDOR ═══ */
.contenedor {
  display: flex;             /* activa flexbox */

  /* Dirección del eje principal */
  flex-direction: row;          /* ← default: izq → der */
  flex-direction: row-reverse;  /* der → izq */
  flex-direction: column;       /* arriba → abajo */
  flex-direction: column-reverse;/* abajo → arriba */

  /* Distribución en el EJE PRINCIPAL */
  justify-content: flex-start;   /* al inicio (default) */
  justify-content: flex-end;     /* al final */
  justify-content: center;       /* centrado */
  justify-content: space-between;/* espacio entre items */
  justify-content: space-around; /* espacio alrededor */
  justify-content: space-evenly; /* espacio igual */

  /* Alineación en el EJE CRUZADO */
  align-items: stretch;          /* estira (default) */
  align-items: flex-start;        /* arriba */
  align-items: flex-end;          /* abajo */
  align-items: center;            /* centrado vertical */
  align-items: baseline;          /* alineados por baseline de texto */

  /* Espacio entre items */
  gap: 16px;              /* igual en filas y columnas */
  gap: 12px 24px;         /* row-gap | column-gap */
  row-gap: 12px;
  column-gap: 24px;

  /* Salto de línea cuando no entra todo */
  flex-wrap: nowrap;   /* una sola línea (default) */
  flex-wrap: wrap;     /* salta a la siguiente línea */
}

/* ═══ HIJOS (flex items) ═══ */
.item {
  flex-grow:   1;     /* cuánto crece para llenar espacio */
  flex-shrink: 1;     /* cuánto achica si no hay espacio */
  flex-basis:  auto; /* tamaño base antes de flex */

  /* shorthand */
  flex: 1;            /* grow:1 shrink:1 basis:0 */
  flex: 0 0 200px;   /* no crece, no achica, 200px fijo */

  align-self: center; /* override de align-items para este item */
  order: 2;            /* orden visual (default:0) */
}

⚖️ Position vs Flexbox

Cuándo usar cada uno — diferencias, escenarios y guía de decisión

▶

Position y Flexbox no compiten: son herramientas con propósitos distintos que se complementan en un mismo diseño. La clave está en entender qué resuelve cada uno.

📍 Usá position cuando…

  • Necesitás superponer elementos (modales, tooltips, overlays)
  • Querés anclar algo al viewport (header fijo, botón flotante)
  • Necesitás que un elemento salga del flujo sin afectar al resto
  • Colocás un badge o etiqueta sobre una tarjeta o imagen
  • Controlás el z-index (capas de apilamiento)
  • Hacés un header sticky que se pega al hacer scroll
  • Posicionás elementos en coordenadas precisas

📦 Usá Flexbox cuando…

  • Tenés múltiples items que distribuir en fila o columna
  • Necesitás centrar fácilmente (horizontal, vertical o ambos)
  • Los elementos deben crecer o achicarse según el espacio
  • Construís una barra de navegación
  • Alineás elementos de diferente altura en la misma fila
  • Hacés un layout de tarjetas con separación uniforme
  • Controlás el orden visual sin cambiar el HTML
⚠️ El error más común
Intentar hacer una grilla de cards con position:absolute y coordenadas manuales para cada card. Esto rompe la responsividad y es imposible de mantener. Para distribución de múltiples elementos en filas/columnas: Flexbox (o CSS Grid). position:absolute es para un elemento posicionado respecto a su contexto.

📋 Tabla comparativa

Característica 📍 position 📦 Flexbox
Afecta al flujo Solo relative/sticky mantienen flujo. absolute/fixed lo rompen. Siempre en flujo normal.
Cuántos elementos Pensado para UN elemento posicionado. Diseñado para MÚLTIPLES hijos.
Referencia Padre posicionado (absolute) o viewport (fixed/sticky). El propio contenedor flex.
Distribución automática No. Se necesitan coordenadas manuales. Sí. justify-content y align-items distribuyen solos.
Responsive Puede ser difícil sin calcular posiciones dinámicas. Muy responsive: flex-wrap y flex-grow adaptan solos.
Capas (z-index) ✓ Sí, con z-index. No. Mismo plano visual.
Centrado vertical top:50% + transform:translateY(-50%) (verboso). align-items:center (una sola línea).
Típico uso Modales, tooltips, headers fijos, badges, overlays. Navbars, cards, formularios, centrado, distribución.
✅ La regla de oro
Si necesitás distribuir varios elementos en fila o columna → Flexbox.
Si necesitás que un elemento se posicione de forma especial respecto a algo → position.

En la mayoría de los layouts reales, usarás ambos: Flexbox para la distribución general y position:absolute para detalles como badges, tooltips o elementos decorativos.

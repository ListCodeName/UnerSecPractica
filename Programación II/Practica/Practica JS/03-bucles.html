Resumen Teórico del Taller

  • for (let i = 0; i < N; i++) se usa cuando conocemos el número exacto de iteraciones.
  • while (condición) itera indefinidamente mientras la condición sea verdadera.
  • do { ... } while (condición) asegura al menos una ejecución previa al chequeo.
  • Bucles anidados consisten en estructuras repetitivas una dentro de la otra para modelar planos 2D o matrices.

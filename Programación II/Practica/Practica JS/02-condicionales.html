Resumen Teórico del Taller

  • if (condición) { ... } else { ... } bifurca el flujo de ejecución.
  • Operadores lógicos: && (Y lógico), || (O lógico), ! (Negación).
  • Operadores relacionales: === (igualdad estricta), !== (desigualdad estricta), >, <=, etc.
  • El bloque switch evalúa una expresión contra múltiples casos de valor.

Resumen Teórico del Taller

  • function nombre(params) { return valor; } encapsula lógica reutilizable.
  • const flecha = (a, b) => a + b; proporciona una sintaxis más corta e implícita.
  • Callbacks: Funciones pasadas como parámetros a otras funciones para ejecutarse más tarde.
  • Closures: Funciones que recuerdan y acceden al entorno léxico donde fueron creadas.

Módulo 5 · Práctica de Animaciones

Animaciones CSS: Keyframes & Bucles Infinitos

Construye una consola de diagnóstico animada con barras de frecuencia y ondas de radar sincronizadas.

Consignas del Ejercicio

01. La Consola de Diagnóstico (`.anim-tarjeta`): Crea el contenedor del panel. En tu CSS, dale un ancho de 280px, alto de 320px, fondo #111322 (gris pizarra), borde de 2px solid #2a2f5a y border-radius: 16px.
Nota de posición: Debe tener position: relative y overflow: hidden para asegurar que la línea del escáner no sobresalga del widget.

02. El Escáner Láser (`.anim-linea-scan`): Dentro del contenedor, crea un div vacío con la clase .anim-linea-scan.
En tu CSS, dale un ancho del 100%, alto de 3px, fondo de degradado horizontal linear-gradient(to right, transparent, #00e5ff, transparent) y posición **absoluta** con left: 0.
La Animación (`@keyframes scan`): Define una animación que barra el widget verticalmente de arriba a abajo.
Configuración de keyframes:
0%, 100% { top: 0%; opacity: 0; } (inicia arriba transparente)
10%, 90% { opacity: 1; } (se vuelve sólido al recorrer)
50% { top: 100%; } (llega abajo)
Asocia la animación a `.anim-linea-scan` con una duración de 3s de forma **infinita** y velocidad **lineal**.

03. El Radar de Pulsación (`.anim-radar` y `.anim-onda`): Crea un div con la clase .anim-radar. En tu CSS, dale un ancho y alto de 70px, fondo translúcido celeste rgba(0, 229, 255, 0.1), borde de 2px solid #00e5ff y redondeado de 50%. Centra la caja horizontalmente con márgenes y dale una posición `relative`.
La Onda Expansiva (`@keyframes radar-pulse`): Dentro de `.anim-radar`, inserta `.anim-onda` de ancho y alto completos, con borde de 2px solid #00e5ff, redondeado al 50% y posición absoluta `top: 0; left: 0;`.
Crea la animación de la onda para que se expanda y se desvanezca:
0% { transform: scale(1); opacity: 1; } (tamaño normal y sólida)
100% { transform: scale(2.2); opacity: 0; } (crece al doble y se vuelve transparente)
Asocia esta animación a `.anim-onda` de manera **infinita** durante 2s con aceleración suave.

04. El Ecualizador Frecuencial (`.anim-ecualizador` y `.anim-barra`): Crea un div contenedor `.anim-ecualizador` con display: flex; justify-content: space-evenly; align-items: flex-end; height: 65px; border-bottom: 1px solid #22263f; padding-bottom: 5px;.
Adentro inserta 4 barras con la clase .anim-barra.
Cada barra debe medir 12px de ancho, 50px de alto, tener fondo magenta #e040fb y esquinas redondeadas de 3px.
Punto de anclaje: Para que crezcan hacia arriba y no hacia abajo, configúrales un transform-origin: bottom.

05. Animación Desfasada (`@keyframes ec-bounce` y `:nth-child()`): Crea la animación para las columnas del ecualizador para que alterne su tamaño vertical:
0%, 100% { transform: scaleY(0.2); }
50% { transform: scaleY(1.2); }
Asocia esta animación a la clase `.anim-barra` para que dure 1.2s de forma **infinita** y suave.
Para lograr la frecuencia asimétrica y desfasada del radar, aplícales diferentes retrasos de tiempo (animation-delay) según su orden de hijos:

  • Primer barra (`:nth-child(1)`): retraso de 0.1s.
  • Segunda barra (`:nth-child(2)`): retraso de 0.4s.
  • Tercer barra (`:nth-child(3)`): retraso de 0.2s.
  • Cuarta barra (`:nth-child(4)`): retraso de 0.6s.

Transiciones de Estado e Interacciones Capturadas

Crea una tarjeta interactiva de Modo Noche controlada enteramente con selectores CSS sin usar Javascript.

Consignas del Ejercicio

01. La Tarjeta Reactiva (`.modo-tarjeta`): Crea un div contenedor `.modo-tarjeta`. En tu CSS, aplícale ancho de 260px, alto de 280px, esquinas redondeadas de 16px y un relleno interno de 24px.
Estilos por defecto (Modo Claro): Fondo blanco #ffffff, color de texto oscuro #0c0e17 y un borde sólido de 2px solid #e2e4f0.
Transición: Agrega una transición suave para el fondo, texto y bordes (`transition: background-color 0.3s, color 0.3s, border-color 0.3s`).

02. El Checkbox Invisible (`.modo-check`): Agrega un `` con la clase .modo-check como primer elemento dentro de la tarjeta. En tu CSS, ocúltalo por completo usando display: none (capturaremos su estado sin verlo).

04. El Evento Checked (`:checked` y `:has()`): Ahora capturaremos las interacciones utilizando pseudo-clases:

  • Desplazar el botón: Cuando el checkbox esté marcado, desplaza el knob horizontalmente. Usa:
    .modo-check:checked + .modo-switch .modo-knob { transform: translateX(26px); }
  • Cambiar el color del Switch: Cuando esté marcado, cambia el fondo del switch track a violeta. Usa:
    .modo-check:checked + .modo-switch { background-color: #7c5cfc; }
  • Activar el Modo Noche en la tarjeta: Usando la pseudo-clase de relación de padres `:has()`, cambia la apariencia de la tarjeta completa cuando su checkbox esté activado. Usa:
    .modo-tarjeta:has(.modo-check:checked) { background-color: #0f111a; color: #ffffff; border-color: #22263f; }

Decoración y Botón de Brillo: Inserta dentro de la tarjeta dos barras simuladas de texto `.modo-linea-a` (ancho 140px, alto 12px, fondo `#e2e4f0`, redondeado 4px) y `.modo-linea-b` (ancho 90px, alto 8px, fondo `#f0f2f8`, redondeado 3px) que cambien a gris oscuro (`#22263f` y `#17192a` respectivamente) al activar el modo noche.
Agrega un botón `.modo-btn-glow` (ancho completo, alto 38px, fondo oscuro `#0c0e17`, color blanco y redondeado 8px, con texto "Confirmar"). Cuando el Modo Noche esté activo en la tarjeta, cámbiale el fondo a violeta `7c5cfc` y dale un brillo neón con `box-shadow: 0 0 15px rgba(124,92,252,0.4)`.

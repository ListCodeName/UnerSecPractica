Crear un <div>

El bloque fundamental del layout en HTML

▶

Un <div> (abreviatura de division) es un elemento de bloque genérico que sirve como contenedor. Por sí solo no muestra nada especial, pero es la base sobre la que construimos toda estructura visual con CSS.

💡 ¿Por qué <div>?
A diferencia de elementos semánticos como <section> o <article>, el <div> no tiene significado propio: es un lienzo en blanco que podemos darle forma con CSS. Ideal para agrupar contenido sin implicar ningún significado adicional.
HTML 
<!-- Un div básico -->
<div>
  Hola, soy un div.
</div>

2

Agregar un selector .class

Agrupando estilos para reutilizarlos

▶

Para darle estilos a un div usamos el atributo class. CSS tiene tres tipos principales de selectores: etiqueta (div), id (#mi-id) y clase (.mi-clase).

🤔 ¿Por qué clase y no id?
Un id debe ser único en toda la página: sirve para identificar un solo elemento. Una class, en cambio, puede aplicarse a múltiples elementos a la vez, lo que permite reutilizar el mismo bloque de estilos sin repetirlo. Esto es el principio DRY (Don't Repeat Yourself). Además, las clases tienen menor especificidad que los ids, facilitando el mantenimiento.
HTML 
<!-- Agregamos la clase "tarjeta" -->
<div class="tarjeta">
  Soy una tarjeta
</div>

<!-- Podemos aplicarla a OTRO div también -->
<div class="tarjeta">
  Soy otra tarjeta con el mismo estilo
</div>
CSS 
/* El punto (.) indica "selector de clase" */
.tarjeta {
  background-color: #00e5ff;
  padding: 12px;
  border-radius: 8px;
}

3

Width, Height & Background

Controlando las dimensiones y el fondo del elemento

▶

Con CSS podemos controlar el tamaño y el color/imagen de fondo de cualquier elemento. Las propiedades clave son: width (ancho), height (alto) y background-color (color de fondo).

CSS – Sintaxis de propiedades de caja 
.caja {
  width:            200px;   /* ancho fijo en píxeles */
  height:           100px;   /* alto fijo en píxeles  */
  background-color: #7c5cfc; /* color de fondo HEX    */

  /* También podemos usar porcentaje o rem: */
  width:  50%;   /* 50% del contenedor padre */
  width:  10rem; /* 10 × tamaño base (16px) = 160px */

  /* border-radius redondea las esquinas */
  border-radius: 8px;
}

Anidamiento de Divs

Hermanos vs. Padre-Hijo

▶

Los divs pueden anidarse: un div puede contener otros divs dentro. Esto crea dos tipos de relaciones que es fundamental distinguir: padre-hijo (un div dentro de otro) y hermanos (divs al mismo nivel).

👨‍👦 Relación Padre → Hijo
Cuando un div está dentro de otro, el externo es el padre y el interno es el hijo. El hijo hereda algunas propiedades del padre y, en CSS, el padre puede afectar al hijo con selectores descendientes.
HTML – Padre e Hijos 
<div class="padre">       <!-- PADRE -->

  <div class="hijo-a">  <!-- HIJO A -->
    Hijo A
  </div>

  <div class="hijo-b">  <!-- HIJO B (hermano de A) -->
    Hijo B
  </div>

</div>
CSS – Estilos de la jerarquía 
.padre {
  width: 300px;
  height: 160px;
  background-color: #7c5cfc33; /* semitransparente */
  border: 3px solid #7c5cfc;
  padding: 14px;
}

.hijo-a {
  width: 100px;  height: 50px;
  background-color: #e040fb;  /* violeta */
  display: inline-block;
}

.hijo-b {
  width: 100px;  height: 50px;
  background-color: #00e5ff;  /* cyan */
  display: inline-block;
}

/* Selector descendiente: solo hijos dentro de .padre */
.padre .hijo-a {
  border-radius: 6px;
}

🤝 Relación Hermanos (siblings)
Dos divs son hermanos cuando están al mismo nivel dentro del mismo padre. No están uno dentro del otro; conviven lado a lado en la jerarquía HTML. En CSS podemos seleccionar al hermano adyacente con + o a todos los hermanos con ~.
HTML – Dos divs hermanos 
<!-- Hermano 1 -->
<div class="seccion">
  Primera sección
</div>

<!-- Hermano 2 – al mismo nivel que el anterior -->
<div class="seccion">
  Segunda sección
</div>

<!-- Selector de hermano adyacente en CSS: -->
<!-- .seccion + .seccion { margin-top: 10px; } -->

📊 Resumen: ¿cuándo es Padre-Hijo y cuándo Hermanos?
Concepto Descripción Selector CSS
Padre → Hijo Un div dentro de otro .padre .hijo
Hermanos Divs al mismo nivel .a + .b   .a ~ .b
Hijo directo Solo el primer nivel hijo .padre > .hijo
